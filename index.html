ประสบการณ์การทำงาน

Frontend Developer Intern — Projectsoft Thailand
6 April – 12 June
  • Developed an NHD Dashboard to visualize claim submission performance for each health-promoting hospital (รพ.สต.), comparing payment amounts before and after NHD implementation through interactive bar charts.
  • Implemented a Top 10 ranking feature to identify health-promoting hospitals with the highest claim amounts for faster performance comparison and analysis.
  • Developed a Drug Catalog Overview with filtering and data download features to provide an overview of medicines used by health-promoting hospitals.
  • Integrated data from the Drug Catalog and 16 drug-dispensing data files into a centralized web interface for easier data analysis and review.
  • Built frontend interfaces and debugged application issues using React, JavaScript, REST API and MUI.
